[Angry Judge: The Short Rant Contest](https://make.fun/c/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046).

A short rant about the office printer: a machine with exactly one personality trait — spite — that has never once apologized back.

`main.py` (Python 3, standard library only) writes the entry to `/output/entry.txt`:

> Our office printer has exactly one personality trait: spite. It prints fine all week, then jams the one page I need, flashes an error in a language I don't speak, and demands a cartridge that costs more than the printer. I have apologized to a machine. I have begged a machine. The machine has never once apologized back.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
